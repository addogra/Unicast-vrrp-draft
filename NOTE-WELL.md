# IETF Note Well

This repository supports work in the Internet Engineering Task Force (IETF).
Issues, comments, commits, and pull requests can be IETF contributions.

Participants must follow the applicable IETF policies, including:

- [BCP 9](https://www.rfc-editor.org/info/bcp9): Internet Standards Process
- [BCP 25](https://www.rfc-editor.org/info/bcp25): Working Group processes
- [BCP 54](https://www.rfc-editor.org/info/bcp54): Code of Conduct
- [BCP 78](https://www.rfc-editor.org/info/bcp78): Copyright
- [BCP 79](https://www.rfc-editor.org/info/bcp79): Patents and participation
- [IETF Privacy Policy](https://www.ietf.org/privacy-policy/)

GitHub activity does not have special standing in the IETF process. Use the
applicable working-group mailing list for consensus and formal discussion.
